# Starting prompt for a new client website

Open an empty folder for the client, put the client's questionnaire, logo, images and documents in `client/inbox` (or attach them to the chat), then paste the prompt below into a new chat.

---

I want to create a professional company website using **Client Website Studio**.

GitHub repository:
https://github.com/eng-same/client-website-studio

Get the kit **outside** this project folder, install the `client-website-studio` skill the way your agent supports (user-level skills folder), read `START.md` from the kit, and follow all its instructions throughout the project. Never copy the kit or the skill into this folder.

I will provide the client's completed questionnaire, logo, images, and any available company documents.

Use this information to create the website according to the skill's design, content, quality, and technical standards. The website files must sit directly in this folder, with `index.html` at the root.

Handle the entire process yourself. Do not ask me technical questions or repeat information already provided. Only ask if essential business information is missing or a decision requires my approval.

Show me the design options, build the website, check everything, and give me one verified `DEPLOY-READY.zip` for Libyan Spider hosting, with simple steps to upload it.

If this is an existing project, continue from the saved progress without overwriting previous work or creating a second site inside it.

Communicate with me in simple Arabic.
Start by loading the skill and reviewing the client information I provide.
