# Starting prompt for a new client website

Open an empty folder for the client, put the client's questionnaire, logo, images and documents in `client/inbox` (or attach them to the chat), then paste the prompt below into a new chat.

---

I want to create a professional company website using **Client Website Studio**.

GitHub repository:
https://github.com/eng-same/client-website-studio

Read `START.md`, load the `client-website-studio` skill, and follow all its instructions throughout the project.

I will provide the client's completed questionnaire, logo, images, and any available company documents.

Use this information to create the website according to the skill's design, content, quality, and technical standards.

Handle the entire process yourself. Do not ask me technical questions or repeat information already provided. Only ask if essential business information is missing or a decision requires my approval.

Show me the design options, build the website, check everything, and prepare the final files for publishing on Libyan Spider cPanel.

If this is an existing project, continue from the saved progress without overwriting previous work.

Communicate with me in simple Arabic.
Start by loading the skill and reviewing the client information I provide.
